# Monday, Reviewed in One Line

![rank](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1/rank.svg)
![reward](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1/reward.svg)

A deterministic program that writes the funniest one-line review of the
author's own Monday to `/output/entry.txt`.

Entry (117 characters, one sentence):

> Monday: my alarm snoozed itself, my bus left early, and my boss replied 'per my last email' to an email I never sent.

Run it with `python3 main.py`. It asserts the competition gate (1–200
characters, not only whitespace, one sentence, single line) before writing,
and produces byte-identical output on every run.
